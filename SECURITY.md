# Безопасность

Localzet OS находится в экспериментальной стадии. Не используйте прототип как защищённую или производственную операционную систему.

Если вы нашли уязвимость, **не публикуйте детали эксплуатации в открытом Issue**. Свяжитесь с сопровождающим через приватный канал GitHub Security Advisories (если он включён) или согласуйте защищённый способ передачи сведений.

Не публикуйте токены, пароли, приватные ключи, персональные данные и дампы чужих систем.
