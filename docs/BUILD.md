# Сборка и проверка

Рабочая среда: отдельная Debian Trixie VM с доступом к сети и достаточным объёмом свободного места.

```bash
sudo apt update
sudo apt install live-build rsync sudo git python3 qemu-system-x86
./scripts/verify-release.sh
./scripts/build-localzet-live.sh
./scripts/test-live-qemu.sh
```

Команды будут доступны после публикации полного дерева исходников. Проверяйте каждый этап отдельно.

**Критерии успешной сборки:** нулевой код завершения сборки, существующий ISO, проверенная контрольная сумма, успешная загрузка в QEMU и работа графической сессии.

Ни один из этих критериев пока не подтверждён на опубликованном релизе.
