# Итерация 14 — Boot Verification

Цель: исключить ложноположительную проверку Live ISO.

- В пакетах Live ISO необходим `waybar`.
- QEMU должен сохранять serial.log и машиночитаемый отчёт.
- Появление сообщений ядра **не доказывает** запуск Wayland.
- Результат `graphical_session_started` остаётся `false`, пока не получено свидетельство от гостевой системы.
- Публикация ISO требует успешной проверки release-gate.

## Следующие проверки

1. Успешная сборка Rust workspace.
2. Сборка Debian Trixie ISO.
3. Загрузка в QEMU и наблюдение за serial-консолью.
4. Инструментированный гостевой сигнал о запуске labwc.
5. Подтверждение запуска GTK-панели и launcher.
6. Создание реальных скриншотов и публикация ISO только после проверок.

Никаких подтверждённых результатов загрузки пока нет.
