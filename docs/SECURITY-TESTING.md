# Проверки безопасности и доказательная база

## Инвентаризация

В полном исходном архиве доступен скрипт `scripts/security-audit.py` с режимом `--json` и unit-тестами.

```bash
python3 scripts/security-audit.py --json > security-inventory.json
python3 -m unittest discover -s tests -p 'test_*.py'
```

Инвентаризация только читает информацию о хосте. Она не доказывает включение или правильность конфигурации механизмов защиты. Наличие `cryptsetup` не означает шифрование диска.

## Критерии защищённой редакции

1. Зафиксировать модель угроз, оборудование, ядро и состав пакетов.
2. Протестировать Secure Boot, TPM, обновления и откат.
3. Подтвердить шифрование, управление ключами и восстановление.
4. Испытать разграничение доступа, изоляцию приложений и аудит.
5. Проверить Docker, GPU-драйверы, NetBird и маршрутизацию.
6. Выполнить независимые испытания и сопоставить результаты с выбранными нормативными требованиями.

**Статус:** проектирование и ранние тесты; сертификации ФСТЭК/ФСБ нет.
