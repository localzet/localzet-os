# Localzet Desktop Alpha M1

Первый продуктовый milestone после итераций 1–20.

## Сделано
- Native GTK4 panel и desktop запускаются из labwc autostart.
- Логи компонентов сохраняются в XDG_RUNTIME_DIR/localzet-os.
- Гостевой маркер V2 появляется только если оба процесса запущены.
- QEMU smoke test больше не принимает маркер V1.

## Ограничения
Маркер подтверждает запуск процессов, а не успешную отрисовку, работоспособность GPU или отсутствие сбоев после проверки. Rust-компиляция, ISO и QEMU пока не подтверждены.

## Критерий M2
Подтверждённая сборка Cargo workspace и Live ISO; затем реальный QEMU boot и скриншот рабочего стола.
