# Localzet OS как рабочая станция

Localzet OS предназначена для разработки и повседневной работы, но сейчас находится в экспериментальной стадии.

## Профили
- **base**: Git/GitHub CLI, PHP/Composer, Python, Node.js, C/C++, сборочные инструменты.
- **containers**: Docker/Compose, Podman.
- **security**: Nmap, Wireshark, tcpdump, Ghidra и другие средства разрешённого аудита.
- **ai**: Python, Jupyter, Git LFS, nvtop, PyTorch (отдельно).
- **dotnet**: .NET SDK из официального источника.

## Сетевые приложения
NetBird устанавливается отдельно из официальных пакетов. FlClashX/Mihomo — отдельный сетевой профиль без изменения DNS и маршрутов по умолчанию. ChatGPT доступен через веб/PWA.

## CUDA
NVIDIA Driver, CUDA Toolkit, PyTorch и NVIDIA Container Toolkit — независимые этапы. Проверяем совместимость драйвера с ядром, DKMS, Secure Boot, PRIME и энергосбережение на ноутбуках. Не встраиваем CUDA в базовый ISO.

## Принципы
- Базовый Live ISO остаётся минимальным.
- Профили устанавливаются явно после установки ОС.
- Никаких токенов GitHub, NetBird или прокси-подписок в образе.
- Никакого автоматического добавления сторонних APT-репозиториев.
- Для основного компьютера обязательны резервные копии, откат, тесты сети, сна, графики и дисков.

Полные исходники и профильный установщик доступны в подготовленном ZIP; публикация полного дерева ещё продолжается.
