# Итерации Localzet OS

| Этап | Работа | Критерий завершения |
|---|---|---|
| 12. Release Integrity | Проверка ISO, SHA-256 и отчёта о загрузке | Нет публикации без доказательств |
| 13. Source Sync | Полный Rust workspace, Cargo.lock, CI | Зелёные проверки GitHub Actions |
| 14. Bootable Alpha | Debian Trixie ISO, QEMU, графическая сессия | Реальная загрузка, логи и скриншоты |
| 15. Secure Base | Secure Boot, TPM2, LUKS2, MAC, аудит | Испытания защитных механизмов |
| 16. Workstation | PHP, Rust, Python, JS/TS, C/C++, C#, Docker/K8s, NetBird | Проверка профилей установки |
| 17. GPU & Laptop | NVIDIA, CUDA, PyTorch, PRIME, энергосбережение | CUDA-тесты и стабильная работа ноутбука |
| 18. Updates & Recovery | Подписанные обновления и откат | Восстановление после сбойного обновления |
| 19. Hardened Edition | SBOM, SAST, политики, изоляция, аудит | Независимая проверка фиксированной конфигурации |
| 20. Certification Track | Требования ФСТЭК/ФСБ, лабораторные испытания | Подтверждающие документы, если сертификация пройдена |

**Приоритет:** 13 → 14 → 15. Пока не подтверждена загрузка ISO, нельзя называть систему готовой к ежедневному использованию.

ФСТЭК/ФСБ: это цели подготовки к оценке соответствия, а не действующие сертификаты.
