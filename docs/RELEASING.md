# Выпуск версий

Используем SemVer. До стабилизации API — версии `0.x.y`, предварительные выпуски `-alpha.N` и `-rc.N`.

## Обязательные условия

1. Все проверки CI успешны.
2. Rust Workspace собирается.
3. Live ISO собирается воспроизводимо.
4. ISO загружается в QEMU и открывает графическую сессию.
5. Опубликованы SHA-256, список известных ограничений и заметки о релизе.
6. Артефакты прикреплены к GitHub Release.

Не создавайте релиз с ISO, если образ не прошёл проверку. Теги не должны вводить пользователей в заблуждение.
