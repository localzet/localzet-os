# Архитектура

Цель проекта — сохранить совместимость Linux и постепенно заменить компоненты пользовательского окружения собственными реализациями на Rust.

## Уровни

1. **Linux Kernel**: драйверы, сеть, управление памятью.
2. **Debian Trixie userspace**: системные библиотеки, пакеты, службы.
3. **labwc / Wayland**: композитор на раннем этапе.
4. **Localzet Runtime**: системные службы, IPC и инструменты управления.
5. **Localzet Desktop**: панель, запуск приложений, настройки.

Собственный композитор — долгосрочная задача. Пока не реализованы надёжные графические драйверы, используется существующая инфраструктура.
