- [ ] Публикация и проверка полного дерева исходников.
- [ ] Успешная сборка Rust Workspace в CI.
- [ ] Воспроизводимая сборка Live ISO.
- [ ] Автоматическая проверка загрузки QEMU.
- [ ] Настоящие скриншоты графической сессии.
- [ ] Панель, launcher, уведомления, настройки.
- [ ] Проверка NVIDIA, Wi-Fi, Bluetooth и энергопотребления.
- [ ] Установщик, обновления и откат.
- [ ] Устанавливаемая система: обновления live-сессии теряются после перезагрузки.
- [ ] До установки показывать только read-only инвентаризацию накопителей, UEFI/BIOS и VMD; не предлагать продолжать при нераспознанном хранилище.
- [ ] До любых записей распознавать Windows/Ubuntu и явно перечислять разделы, которые будут сохранены, форматированы или изменены.
- [ ] По умолчанию сохранять существующую ESP и разделы данных; назначать форматирование только по отдельному явному выбору.
- [ ] Перед записью повторно сверять выбранные диски по стабильным идентификаторам и показывать полный план изменений с финальным подтверждением.
- [ ] Центр обновлений с перечнем пакетов и версий, зависимостями, размером загрузки/установки, удалениями, перезапуском служб и требованием перезагрузки до подтверждения.
- [ ] Подтвердить Ubuntu 26.04 `resolute`, APT/security updates и GNOME Software в загруженном образе; сторонние PPA не включать в базовый образ.
- [ ] План отката обновлений ядра и системы.
- [ ] Первый публичный alpha-релиз с проверенным ISO.
