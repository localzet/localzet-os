# Итерация 15 — контроль исходников

В локальном архиве добавлен `scripts/check-repository-integrity.py`, который проверяет обязательные файлы, шесть Rust-крейтов, наличие Rust-исходников и некоторые случайные утечки приватных ключей.

Запуск:

```bash
python3 scripts/check-repository-integrity.py --json
python3 -m unittest discover -s tests -p 'test_*.py'
```

**Локальные результаты:** 11 тестов пройдены, структура проекта проверена, ZIP валиден.

## Ограничения

- Этот контроль не заменяет полноценное сканирование секретов, SAST, анализ зависимостей или ручной аудит.
- Исходники Rust пока не опубликованы целиком в GitHub.
- Rust-компиляция и загрузка ISO пока не подтверждены.
- ФСТЭК/ФСБ-сертификации нет.
