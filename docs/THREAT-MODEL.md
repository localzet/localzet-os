# Начальная модель угроз

## Защищаемые активы
Ключи загрузки и шифрования, учётные записи, токены GitHub/NetBird, SSH-ключи, исходники, модели и датасеты, обновления и журналы.

## Угрозы
1. Кража токенов через npm/pip/cargo-зависимости.
2. Подмена обновлений или артефактов CI.
3. Выход из контейнера через Docker socket.
4. Физический доступ к ноутбуку.
5. Уязвимые драйверы GPU и CUDA-контейнеры.
6. Утечка рабочих данных через облачные приложения.
7. Злоупотребление привилегиями локального администратора.

## Противодействие
Минимальные привилегии, sandbox, проверяемые обновления, LUKS2, TPM, аудит, изоляция рабочих профилей, управление секретами и воспроизводимые испытания.

Для каждого риска необходимы ответственный, тест, критерий остаточного риска и ссылка на свидетельство проверки.
