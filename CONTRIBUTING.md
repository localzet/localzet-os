# Участие в разработке

Спасибо за интерес к Localzet OS.

## Порядок работы

1. Создайте Issue с описанием проблемы или предложения.
2. Создайте ветку от `main`.
3. Добавьте изменения и тесты, если это применимо.
4. Откройте Pull Request с инструкцией по воспроизведению и проверке.

## Коммиты

Используем **Conventional Commits**: `feat:`, `fix:`, `docs:`, `test:`, `build:`, `ci:`, `refactor:`, `chore:`.

Пример: `feat(panel): добавить переключение рабочих пространств`.

Описание коммита может быть на русском; префиксы оставляем стандартными.

Не заявляйте об успешной загрузке, поддержке оборудования или производительности без воспроизводимых результатов.
